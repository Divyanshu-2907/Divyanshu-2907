# Hi, I'm Divyanshu

Software engineer who likes hard bugs. I build AI agents and full-stack products, and I spend a lot of time on the question of how you check whether an AI coding agent actually reasoned through a problem or just pattern-matched its way to something that looks right.

Right now I'm an Analyst at Turing, evaluating LLM responses. Before that I was an AI Fellow at Handshake AI, designing evaluation tasks for AI coding agents.

I also come from hardware (B.Tech in ECE, 2026). My capstone, **HexMind**, is a 25-DOF hexapod robot with real-time inverse kinematics, a YOLOv8 vision pipeline and an MCP-based AI co-pilot you can talk to in plain English. It won Best Paper at NCETST-2026 and I demoed it at Anthropic's Built with Claude Hackathon. When a bug on a robot means a power sag resets the board or the IK solver ignores a joint limit, the machine falls over. Working through that taught me to ask early whether a failure is a math problem, a timing problem or a physical one, because from the outside they all look the same.

- **Turing** (current) — Analyst, evaluating LLM responses
- **Infosys Springboard** — built Java full-stack modules end to end (Spring Boot, Hibernate)
- **CertifyO** — full-stack intern, shipped features on a live Node.js/MongoDB platform with Redis caching
- **Handshake AI** — AI Fellow, designed evaluation tasks for AI coding agents

600+ LeetCode problems solved, mostly in Java.

Currently open to remote software and AI engineering roles.
